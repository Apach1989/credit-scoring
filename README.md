# GP_ML_scoring
Ссылка на датасет: https://www.kaggle.com/datasets/wordsforthewise/lending-club

## Задачи проекта

В рамках проекта были реализованы две задачи машинного обучения на данных LendingClub.

### Регрессия

Построение модели для прогнозирования процентной ставки по кредиту (`int_rate`).

Были выполнены:

- разведочный анализ данных;
- предобработка признаков;
- сравнение алгоритмов регрессии;
- подбор гиперпараметров CatBoost с помощью Optuna;
- анализ важности признаков.

### Классификация

Построение модели для прогнозирования статуса кредита (`loan_status`).

Модель определяет, будет ли кредит успешно погашен или перейдет в дефолт.

В рамках задачи были выполнены:

- подготовка данных;
- кодирование категориальных признаков;
- сравнение нескольких алгоритмов классификации;
- подбор гиперпараметров;
- оценка качества по ROC-AUC и PR-AUC.
